Copyframe 隐私政策

生效日期：2026 年 8 月 10 日

Copyframe 仅在用户明确点击“复制整页”“选择元素”或“保存网页副本”后，将当前网页转换为可粘贴到 Figma 的设计图层、独立 HTML 区块或下载的离线网页包。

我们处理的数据

在用户主动发起一次采集时，Copyframe 会在浏览器本机读取当前网页中与导出有关的内容：页面结构、可见文本、布局和样式信息、图片和字体等资源引用，以及已填写的非密码表单内容。密码输入框的值不会被采集。

“复制到 Figma”会把生成的 HTML/SVG 内容写入系统剪贴板；Copyframe 不会代替用户上传内容到 Figma 或其他服务。

独立 HTML 的隔离预览会把用户刚刚生成的 HTML 临时保存在 Chrome 本地存储中，并使用随机预览标识打开扩展自己的预览页。预览内容最多保留 30 分钟；再次打开过期预览或生成新预览时会自动清理。预览禁用原网页脚本、接口请求与表单提交。

为帮助用户辨认最近操作，扩展会在 Chrome 本地存储中保留最近 5 次采集的页面标题、已移除查询参数和锚点的网址、图标、类型与轻量诊断信息。只有最近一次采集会额外保留用于“重新复制”的生成内容，后续采集会替换它。这些记录各自最多保留 24 小时，用户可在扩展的“最近记录”中点击“清除本机记录”立即删除。

“导出离线网页”会在本机生成 ZIP 文件。网页包可能包含从页面快照提取的结构摘要、响应式断点和颜色、字体、间距等设计候选值，供用户或 AI 在本地继续开发。生成过程中的临时 ZIP 数据在交给浏览器下载后删除；最终下载文件保留在用户选择的位置，由用户自行管理和删除。

数据传输与第三方

Copyframe 不运营接收采集内容的服务器，也不会将页面内容、剪贴板内容、浏览历史、分析数据或个人信息出售、出租、共享或传输给开发者或第三方。

为了将当前页面的图片、字体、样式等资源嵌入导出结果，扩展可能直接向该页面引用的资源地址发起浏览器请求。请求从用户的浏览器直接发送到原网页或其资源提供方，不会经过 Copyframe 服务器；在用户已经登录相关网站时，请求可能携带该网站正常使用所需的浏览器凭据。用户可在首次采集时拒绝网站访问权限；此时不会开始采集。

用户主动点击“获取 Viewer”时，扩展会打开 Copyframe Viewer 的 GitHub 发布页。该链接不会自动打开，也不会向 Copyframe 发送采集内容。

Copyframe Viewer 默认不访问外部网络。离线页面不能自行开启远程资源，也不能静默打开系统浏览器；用户点击外部链接时 Viewer 会先显示确认。只有用户主动点击“加载缺失资源”后，当前离线包才会临时允许加载外部图片和媒体，关闭 Viewer 或切换离线包后即恢复默认状态。

权限说明

  • activeTab 与 scripting：仅在用户点击扩展后读取并处理当前网页。
  • 可选网站访问权限：在用户开始采集时请求，用于读取网页引用的跨域图片、字体和样式资源；不会在未操作时执行。
  • clipboardWrite：按用户操作把生成的设计内容写入剪贴板。
  • storage 与 unlimitedStorage：临时保存最近记录、最近一次采集结果、HTML 预览和生成下载文件所需的数据。
  • downloads 与 offscreen：在本机生成并下载离线网页 ZIP。
  • alarms：在本机安排最近记录的到期清理，不用于后台联网、轮询或持续采集。

用户选择

Copyframe 不会在后台持续监测网页。用户可以在浏览器扩展管理页撤销网站访问权限、卸载扩展，或使用扩展内的“清除本机记录”删除最近记录与最近一次可重新复制内容。

联系方式

如对本隐私政策或数据处理有疑问，请通过 Copyframe Viewer GitHub Issues 联系我们。
